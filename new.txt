## 12) src/components/Auth.tsx

This handles sign-up and sign-in for **students** and **teachers**. On sign-up we store a row in `profiles` (Supabase table) with a `role` field.

```tsx
import React, { useState } from 'react'
import { supabase } from '../lib/supabaseClient'

export default function Auth() {
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [role, setRole] = useState<'student'|'teacher'>('student')
  const [loading, setLoading] = useState(false)
  const [message, setMessage] = useState<string | null>(null)

  async function signUp() {
    setLoading(true)
    setMessage(null)
    try {
      const { data, error } = await supabase.auth.signUp({ email, password })
      if (error) throw error
      // create profile with role — you'll have to create the profiles table in Supabase
      if (data.user) {
        await supabase.from('profiles').upsert({ id: data.user.id, email, role })
      }
      setMessage('Check your email for confirmation (if enabled)')
    } catch (err: any) {
      setMessage(err.message ?? 'Sign up failed')
    } finally {
      setLoading(false)
    }
  }

  async function signIn() {
    setLoading(true)
    setMessage(null)
    try {
      const { error } = await supabase.auth.signInWithPassword({ email, password })
      if (error) throw error
      setMessage('Signed in successfully')
    } catch (err: any) {
      setMessage(err.message ?? 'Sign in failed')
    } finally {
      setLoading(false)
    }
  }

  return (
    <div className="max-w-md mx-auto">
      <div className="card shadow-md">
        <div className="card-body">
          <h2 className="card-title">Sign in / Sign up</h2>
          <div className="form-control">
            <label className="label"> <span className="label-text">Email</span></label>
            <input className="input input-bordered" value={email} onChange={e => setEmail(e.target.value)} />
          </div>
          <div className="form-control">
            <label className="label"> <span className="label-text">Password</span></label>
            <input type="password" className="input input-bordered" value={password} onChange={e => setPassword(e.target.value)} />
          </div>

          <div className="form-control">
            <label className="label"> <span className="label-text">I am a</span></label>
            <select className="select select-bordered" value={role} onChange={e => setRole(e.target.value as any)}>
              <option value="student">Student</option>
              <option value="teacher">Teacher</option>
            </select>
          </div>

          {message && <div className="text-sm text-gray-600">{message}</div>}

          <div className="card-actions justify-end mt-4">
            <button className="btn" onClick={signIn} disabled={loading}>Sign in</button>
            <button className="btn btn-primary" onClick={signUp} disabled={loading}>Sign up</button>
          </div>
        </div>
      </div>
    </div>
  )
}
```

**Notes:**
- Create a `profiles` table in Supabase (schema provided below) that stores user id, email, display name, role.
- You can link RLS policies to limit who can write which data if needed.

## 13) src/components/RatingForm.tsx

A component to submit or update a rating for a teacher. It prevents duplicate ratings by the same user by performing an upsert keyed by (teacher_id, student_id) — implement with a unique constraint in Supabase.

```tsx
import React, { useState, useEffect } from 'react'
import { supabase } from '../lib/supabaseClient'

type Props = { teacherId: string; onSaved?: () => void }

export default function RatingForm({ teacherId, onSaved }: Props) {
  const [score, setScore] = useState(5)
  const [comment, setComment] = useState('')
  const [loading, setLoading] = useState(false)

  async function submitRating() {
    setLoading(true)
    try {
      const user = supabase.auth.getUser ? (await supabase.auth.getUser()).data.user : null
      if (!user) throw new Error('You must sign in to rate')
      const student_id = user.id
      // Upsert rating — requires unique (teacher_id, student_id) constraint in SQL
      const { error } = await supabase.from('ratings').upsert({ teacher_id: teacherId, student_id, score, comment }, { onConflict: ['teacher_id', 'student_id'] })
      if (error) throw error
      if (onSaved) onSaved()
    } catch (err: any) {
      alert(err.message ?? 'Failed to save rating')
    } finally {
      setLoading(false)
    }
  }

  return (
    <div className="card p-4">
      <div className="form-control">
        <label className="label"><span className="label-text">Score (1-5)</span></label>
        <select className="select select-bordered" value={score} onChange={e => setScore(Number(e.target.value))}>
          {[5,4,3,2,1].map(s => <option key={s} value={s}>{s}</option>)}
        </select>
      </div>
      <div className="form-control mt-2">
        <label className="label"><span className="label-text">Comment</span></label>
        <textarea className="textarea textarea-bordered" value={comment} onChange={e => setComment(e.target.value)} />
      </div>
      <div className="mt-3 text-right">
        <button className="btn btn-primary" onClick={submitRating} disabled={loading}>Submit</button>
      </div>
    </div>
  )
}
```

## 14) src/components/TeacherListing.tsx

This is the updated and complete teacher listing component (includes Top Ranked badge, sorting, filtering, skeletons, responsive grid).

> Note: This file is the same component previously created but now references the SQL view `teacher_aggregates` (see SQL below). If you haven't created that view, the component falls back to computing averages from joined ratings.

```tsx
import React, { useEffect, useMemo, useState } from 'react'
import { useNavigate } from 'react-router-dom'
import { supabase } from '../lib/supabaseClient'

type Teacher = {
  id: string
  name: string
  institute: string
  avatar_url?: string | null
  bio?: string | null
  average_rating?: number | null
  ratings_count?: number | null
}

const clamp = (v: number, min = 0, max = 5) => Math.max(min, Math.min(max, v))

const RatingStars: React.FC<{ rating: number; size?: number; className?: string }> = ({ rating, size = 16, className = '' }) => {
  const full = Math.floor(rating)
  const half = rating - full >= 0.5
  const empty = 5 - full - (half ? 1 : 0)
  return (
    <div className={`flex items-center gap-1 ${className}`} aria-hidden>
      {Array.from({ length: full }).map((_, i) => (
        <svg key={`f${i}`} width={size} height={size} viewBox="0 0 24 24" fill="currentColor" className="text-yellow-400">
          <path d="M12 .587l3.668 7.431L23.5 9.75l-5.75 5.6L19.334 24 12 20.2 4.666 24l1.584-8.65L.5 9.75l7.832-1.732z" />
        </svg>
      ))}
      {half && (
        <svg width={size} height={size} viewBox="0 0 24 24" className="text-yellow-400">
          <defs>
            <linearGradient id="half-grad">
              <stop offset="50%" stopColor="currentColor" />
              <stop offset="50%" stopColor="transparent" />
            </linearGradient>
          </defs>
          <path d="M12 .587l3.668 7.431L23.5 9.75l-5.75 5.6L19.334 24 12 20.2 4.666 24l1.584-8.65L.5 9.75l7.832-1.732z" fill="url(#half-grad)" />
        </svg>
      )}
      {Array.from({ length: empty }).map((_, i) => (
        <svg key={`e${i}`} width={size} height={size} viewBox="0 0 24 24" fill="none" stroke="currentColor" className="text-gray-300">
          <path d="M12 .587l3.668 7.431L23.5 9.75l-5.75 5.6L19.334 24 12 20.2 4.666 24l1.584-8.65L.5 9.75l7.832-1.732z" />
        </svg>
      ))}
    </div>
  )
}

export default function TeacherListing() {
  const [teachers, setTeachers] = useState<Teacher[] | null>(null)
  const [loading, setLoading] = useState(false)
  const [search, setSearch] = useState('')
  const [sort, setSort] = useState<'rating_desc' | 'rating_asc' | 'institute_az'>('rating_desc')
  const [selectedInstitute, setSelectedInstitute] = useState<string | 'all'>('all')
  const navigate = useNavigate()

  useEffect(() => {
    fetchTeachers()
  }, [])

  async function fetchTeachers() {
    setLoading(true)
    try {
      // Try to fetch teacher aggregates view first (server-side averages)
      const { data: agg, error: aggErr } = await supabase.from('teacher_aggregates').select('*')
      if (!aggErr && agg && agg.length > 0) {
        // join to teachers to get basic info
        const { data: tdata, error: terr } = await supabase.from('teachers').select('*')
        if (terr || !tdata) throw terr ?? new Error('Failed to fetch teachers')
        const merged = tdata.map((t: any) => {
          const a = agg.find((x: any) => x.teacher_id === t.id)
          return {
            id: t.id,
            name: t.name,
            institute: t.institute,
            avatar_url: t.avatar_url,
            bio: t.bio,
            average_rating: a ? +(+a.avg_rating).toFixed(2) : null,
            ratings_count: a ? +a.ratings_count : 0,
          }
        })
        setTeachers(merged)
        return
      }

      // Fallback: fetch teachers with nested ratings and compute client-side
      const { data, error } = await supabase.from('teachers').select('id, name, institute, avatar_url, bio, ratings:ratings(score)')
      if (error) throw error
      const mapped: Teacher[] = (data ?? []).map((t: any) => {
        const scores: number[] = Array.isArray(t.ratings) ? t.ratings.map((r: any) => r.score) : []
        const ratings_count = scores.length
        const average_rating = ratings_count ? +(scores.reduce((s: number, v: number) => s + v, 0) / ratings_count).toFixed(2) : null
        return {
          id: t.id,
          name: t.name,
          institute: t.institute,
          avatar_url: t.avatar_url,
          bio: t.bio,
          average_rating,
          ratings_count,
        }
      })
      setTeachers(mapped)
    } catch (err) {
      console.error('Failed to load teachers', err)
      setTeachers([])
    } finally {
      setLoading(false)
    }
  }

  const institutes = useMemo(() => {
    if (!teachers) return []
    return Array.from(new Set(teachers.map(t => t.institute))).sort()
  }, [teachers])

  const topTeacherId = useMemo(() => {
    if (!teachers || teachers.length === 0) return null
    const sorted = [...teachers].sort((a, b) => (b.average_rating ?? 0) - (a.average_rating ?? 0) || (b.ratings_count ?? 0) - (a.ratings_count ?? 0) || a.name.localeCompare(b.name))
    return sorted[0].id
  }, [teachers])

  const displayed = useMemo(() => {
    if (!teachers) return []
    let arr = teachers.slice()
    if (selectedInstitute !== 'all') arr = arr.filter(t => t.institute === selectedInstitute)
    if (search.trim()) {
      const q = search.trim().toLowerCase()
      arr = arr.filter(t => t.name.toLowerCase().includes(q) || (t.institute ?? '').toLowerCase().includes(q) || (t.bio ?? '').toLowerCase().includes(q))
    }
    if (sort === 'rating_desc') arr.sort((a, b) => (b.average_rating ?? 0) - (a.average_rating ?? 0) || (b.ratings_count ?? 0) - (a.ratings_count ?? 0))
    else if (sort === 'rating_asc') arr.sort((a, b) => (a.average_rating ?? 0) - (b.average_rating ?? 0) || (b.ratings_count ?? 0) - (a.ratings_count ?? 0))
    else if (sort === 'institute_az') arr.sort((a, b) => (a.institute ?? '').localeCompare(b.institute ?? ''))
    return arr
  }, [teachers, search, sort, selectedInstitute])

  return (
    <div className="p-4 md:p-8 max-w-7xl mx-auto">
      <header className="flex flex-col sm:flex-row sm:items-center sm:justify-between gap-4 mb-6">
        <div>
          <h1 className="text-2xl md:text-3xl font-bold">Teachers</h1>
          <p className="text-sm text-gray-500">Browse teachers, see ratings and profiles. Top ranked teacher gets a special badge.</p>
        </div>

        <div className="flex gap-2 items-center">
          <input value={search} onChange={e => setSearch(e.target.value)} placeholder="Search name, institute or bio" className="input input-bordered w-64" />
          <select className="select select-bordered" value={sort} onChange={e => setSort(e.target.value as any)}>
            <option value="rating_desc">Top rated</option>
            <option value="rating_asc">Lowest rated</option>
            <option value="institute_az">Institute A–Z</option>
          </select>
          <select className="select select-bordered" value={selectedInstitute} onChange={e => setSelectedInstitute(e.target.value as any)}>
            <option value="all">All institutes</option>
            {institutes.map(ins => <option key={ins} value={ins}>{ins}</option>)}
          </select>
        </div>
      </header>

      {loading && (
        <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">
          {Array.from({ length: 6 }).map((_, i) => (
            <div key={i} className="card p-4 shadow-sm animate-pulse">
              <div className="flex items-center gap-4">
                <div className="w-16 h-16 rounded-full bg-gray-200" />
                <div className="w-full">
                  <div className="h-4 bg-gray-200 rounded w-3/4 mb-2" />
                  <div className="h-3 bg-gray-200 rounded w-1/2" />
                </div>
              </div>
            </div>
          ))}
        </div>
      )}

      {!loading && (
        <section>
          <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-4">
            {displayed.map(t => (
              <article key={t.id} className="card bg-base-100 shadow-md hover:shadow-lg transition-shadow">
                <div className="card-body p-4">
                  <div className="flex items-start gap-4">
                    <div className="relative">
                      <img src={t.avatar_url ?? '/placeholder-avatar.png'} alt={`${t.name} avatar`} className="w-16 h-16 rounded-full object-cover" />
                      {t.id === topTeacherId && <span className="badge badge-primary absolute -right-1 -top-1">Top Ranked</span>}
                    </div>
                    <div className="flex-1">
                      <h3 className="font-semibold text-lg">{t.name}</h3>
                      <p className="text-sm text-gray-500">{t.institute}</p>
                      <div className="mt-2 flex items-center justify-between">
                        <div className="flex items-center gap-3">
                          <RatingStars rating={clamp(t.average_rating ?? 0)} />
                          <div className="text-sm text-gray-600">{t.average_rating ? t.average_rating.toFixed(2) : 'No ratings'}</div>
                        </div>
                        <div className="text-xs text-gray-400">{(t.ratings_count ?? 0) > 0 ? `${t.ratings_count} reviews` : '—'}</div>
                      </div>
                    </div>
                  </div>

                  <p className="mt-3 text-sm text-gray-600 line-clamp-3">{t.bio ?? 'No bio yet'}</p>

                  <div className="card-actions mt-4">
                    <button className="btn btn-outline btn-sm" onClick={() => navigate(`/teacher/${t.id}`)}>View profile</button>
                    <button className="btn btn-primary btn-sm" onClick={() => navigate(`/teacher/${t.id}#rate`)}>Rate</button>
                  </div>
                </div>
              </article>
            ))}

            {displayed.length === 0 && (<div className="col-span-full text-center py-12"><p className="text-gray-500">No teachers match your filters.</p></div>)}
          </div>
        </section>
      )}
    </div>
  )
}
```

## 15) src/pages/TeacherProfile.tsx

Profile page shows teacher details, aggregated rating, list of reviews and rating form.

```tsx
import React, { useEffect, useState } from 'react'
import { useParams } from 'react-router-dom'
import { supabase } from '../lib/supabaseClient'
import RatingForm from '../components/RatingForm'

export default function TeacherProfile() {
  const { id } = useParams()
  const [teacher, setTeacher] = useState<any>(null)
  const [reviews, setReviews] = useState<any[]>([])
  const [loading, setLoading] = useState(false)

  useEffect(() => {
    if (!id) return
    load()
  }, [id])

  async function load() {
    setLoading(true)
    try {
      // Fetch teacher with aggregate if available
      const { data: tdata } = await supabase.from('teachers').select('*, ratings:ratings(*)').eq('id', id).single()
      if (!tdata) return
      const scores = Array.isArray(tdata.ratings) ? tdata.ratings.map((r: any) => r.score) : []
      const avg = scores.length ? +(scores.reduce((a: number, b: number) => a + b, 0) / scores.length).toFixed(2) : null
      setTeacher({ ...tdata, average_rating: avg, ratings_count: scores.length })

      const { data: rev } = await supabase.from('ratings').select('score, comment, created_at, student:profiles(display_name)').eq('teacher_id', id).order('created_at', { ascending: false })
      setReviews(rev ?? [])
    } catch (err) {
      console.error(err)
    } finally {
      setLoading(false)
    }
  }

  if (!id) return <div>Invalid teacher</div>

  return (
    <div className="max-w-4xl mx-auto">
      <div className="card bg-base-100 shadow">
        <div className="card-body">
          {loading && <div>Loading...</div>}
          {!loading && teacher && (
            <>
              <div className="flex items-center gap-4">
                <img src={teacher.avatar_url ?? '/placeholder-avatar.png'} className="w-24 h-24 rounded-full object-cover" />
                <div>
                  <h2 className="text-2xl font-bold">{teacher.name}</h2>
                  <div className="text-sm text-gray-500">{teacher.institute}</div>
                  <div className="mt-2">Average: {teacher.average_rating ?? 'No ratings'} ({teacher.ratings_count ?? 0} reviews)</div>
                </div>
              </div>

              <div className="mt-4">
                <h3 className="font-semibold">About</h3>
                <p className="text-gray-600">{teacher.bio ?? 'No bio'}</p>
              </div>

              <div className="mt-6" id="rate">
                <h3 className="font-semibold mb-2">Rate this teacher</h3>
                <RatingForm teacherId={id} onSaved={() => load()} />
```

## 17) supabase/schema.sql

Run this in Supabase SQL editor to create the necessary tables, constraints, and a view for aggregates. Adjust types to your needs.

```sql
-- Profiles (user metadata)
create table if not exists profiles (
  id uuid primary key,
  email text,
  display_name text,
  role text check (role in ('student','teacher')),
  created_at timestamptz default now()
);

-- Teachers
create table if not exists teachers (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  institute text,
  avatar_url text,
  bio text,
  created_at timestamptz default now()
);

-- Ratings
create table if not exists ratings (
  id uuid primary key default gen_random_uuid(),
  teacher_id uuid references teachers(id) on delete cascade,
  student_id uuid references profiles(id) on delete set null,
  score int check (score >= 1 and score <= 5),
  comment text,
  created_at timestamptz default now(),
  updated_at timestamptz
);

-- Unique constraint to prevent duplicate rating rows (teacher_id + student_id)
create unique index if not exists ratings_teacher_student_unique on ratings(teacher_id, student_id);

-- Trigger to update updated_at
create or replace function trg_set_updated_at() returns trigger as $$
begin
  new.updated_at = now();
  return new;
end$$ language plpgsql;

create trigger set_updated_at before update on ratings for each row execute function trg_set_updated_at();

-- Aggregates view (server-side averages)
create or replace view teacher_aggregates as
select
  teacher_id,
  avg(score)::numeric(3,2) as avg_rating,
  count(*) as ratings_count
from ratings
group by teacher_id;
```

## 18) Additional notes & instructions

1. **Supabase Auth & Profiles**
   - After a user signs up via `supabase.auth.signUp`, we create/update a `profiles` row with their role. You can also use Supabase Auth's OAuth providers.
   - For better security, enable RLS (Row Level Security) and create policies ensuring only the owner can edit their profile, only authenticated users can insert ratings, etc.

2. **Prevent duplicate ratings**
   - The SQL `unique index` on `(teacher_id, student_id)` ensures upserts work as intended. Use `upsert` client-side.

3. **Top Ranked badge**
   - The frontend computes the top-ranked teacher using `average_rating` and `ratings_count` tiebreaker. Because we provide the `teacher_aggregates` view, this calculation can be done server-side as well.

4. **Performance**
   - For many teachers & ratings, prefer server-side aggregation (the `teacher_aggregates` view). You can also create materialized views and refresh periodically.

5. **Styling**
   - Tailwind + DaisyUI are used. The UI is responsive with grid breakpoints; DaisyUI provides consistent components.

6. **Running locally**
   - Install deps: `npm install`
   - Start dev server: `npm run dev`

7. **Environment variables**
   - Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to `.env` in the project root.

8. **Suggested improvements**
   - Add input sanitization and character limits to rating comments.
   - Add email verification requirement if desired.
   - Add admin moderation tools to remove abusive comments.
   - Add pagination for teacher listing and caching for large datasets.
